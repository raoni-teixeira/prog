Do código repetido ao while

Todo laço começa como um código repetido. A tarefa é enxergar, dentro dele, o que se repete e o que muda.

sem laço — 5 linhas
1printf("%d\n", 1); 2printf("%d\n", 2); 3printf("%d\n", 3); 4printf("%d\n", 4); 5printf("%d\n", 5);
→
com laço — a mesma saída
1int i = 1; 2while (i <= 5) { 3 printf("%d\n", i); 4 i = i + 1; 5}

    O código sem laço

    Este programa resolve o problema sem nenhuma repetição: cada passo está escrito à mão. Leia com calma e execute. Ele funciona — o problema é que ele não cresce.
